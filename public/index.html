DÚVIDAS FREQUENTES

Você pergunta.
O NexFlow responde.

O NexFlow já está pronto para uso comercial?

Não. A plataforma está em desenvolvimento e ainda depende de autenticação multiusuário, banco de dados e infraestrutura de produção.

Preciso programar para criar fluxos?

A proposta é facilitar a criação visual. Recursos de lógica avançada ainda serão ampliados.

Vai integrar WhatsApp e inteligência artificial?

Sim, estão previstos no roadmap, mas precisam de provedores externos e suas respectivas credenciais.

Onde os dados ficarão armazenados?

Atualmente o backend local usa persistência de desenvolvimento. A versão SaaS será preparada para Supabase.
